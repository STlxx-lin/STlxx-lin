### 📦 Featured Projects & Plugins

#### 🧩 NocoBase 企业级插件矩阵
> 为 NocoBase 提供开箱即用、覆盖文件处理、操作审计、视觉扩展与权限安全的高质量插件。

- [**nocobase-plugin-file-previewer-kkfileview**](https://github.com/STlxx-lin/nocobase-plugin-file-previewer-kkfileview)  
  *多引擎文件预览插件*：集成 kkFileView、BaseMetas 与离线 File Viewer，完整支持 Office、PDF、CAD、3D 模型与多媒体格式。
- [**nocobase-plugin-logger-pro**](https://github.com/STlxx-lin/nocobase-plugin-logger-pro)  
  *企业级日志控制台与操作审计管理插件*：全链路请求追踪、慢 SQL 监控与实时异常告警控制台。
- [**nocobase-plugin-custom-icons**](https://github.com/STlxx-lin/nocobase-plugin-custom-icons)  
  *自定义图标库与海量 SVG 扩展*：支持 Iconfont 一键导入、多源批量上传与原生拾色器。
- [**nocobase-plugin-custom-login-page**](https://github.com/STlxx-lin/nocobase-plugin-custom-login-page)  
  *可视化自定义登录页与模块扩展*：网格卡片引擎驱动、多类专属区块与高并发缓存保障。
- [**nocobase-plugin-attachment-cleaner**](https://github.com/STlxx-lin/nocobase-plugin-attachment-cleaner)  
  *附件智能清理与生命周期管理*：支持孤立附件扫描、文件去重、隔离回收站与定时清理任务。
- [**awesome-nocobase**](https://github.com/STlxx-lin/awesome-nocobase)  
  *NocoBase 精选插件与资源收录合集*。

#### 🚀 跨端与智能硬件 / AI 工具
- [**EVCam-lk06**](https://github.com/STlxx-lin/EVCam-lk06)  
  针对吉利银河E5定制开发的车内环视摄像头行车记录仪应用，兼具远程实时监看的“千里眼”功能。
- [**NovelForge**](https://github.com/STlxx-lin/NovelForge)  
  AI 辅助长篇小说创作工具，基于 JSON Schema 结构化内容生成与卡片式上下文管理。
- [**asset-tickets**](https://github.com/STlxx-lin/asset-tickets)  
  多角色协作工单管理系统（基于 PySide6 + PHP + MySQL）。
